# 宣传片模式（Showcase Mode）—— 去模板化的第二渲染范式

> **一句话**：讲解模式让观众「看懂」，宣传片模式让观众「被击中」。
> 同一套渲染器、同一套帧契约，区别只在 **设计主语** 与 **节奏来源**。

**什么时候读这篇**：做技能发布片 / 产品宣传片 / 作品集 / 发布会开场；
或用户说「不要模板化」「要有设计感」「要自带运镜」；或要**全量展示某个能力库**（动效库、模板库）。

配套读：`references/motion-library.md`（动作词汇）、`references/library-showcase.md`（库全量演示编排）、
`references/style-director.md`（风格编排器）。

---

## 1. 两种范式对照（先分清楚在做哪一种）

| 维度 | 讲解模式（默认） | 宣传片模式（本文） |
|---|---|---|
| 信息载体 | **解说是主**，画面是解说的图示 | **画面是主**，解说退到「标点」位置 |
| 节奏来源 | 字幕块（`B()` 节拍器），解说的吐字时刻 | **动作的因果链**，一拍引发下一拍 |
| 观众状态 | 要「搞清楚这是什么」 | 已知是什么，要「被说服它有多好」 |
| 典型时长 | 30 s – 20 min | 10 – 150 s |
| 画面语言 | 构图清楚、一焦点、可读优先 | **运动优先**：运镜、动能文字、级联承接 |
| 失败形态 | 读不懂 | 像 PPT（一个一个展示、转场生硬、没有承接） |

**混合是允许且推荐的**：全片用讲解骨架，但**每一章用宣传片语言开场** ——
这就是确认点里的「主视觉 + 章节讲解」。

## 2. 六条设计律（每条都给判据，能测）

| # | 律 | 判据（不满足就是违规） |
|---|---|---|
| 1 | **一个主语** | 每场只有**一个**元素是「主语」，其余都是它的**结果**。同屏两个平级主语 = 违规 |
| 2 | **每个反应都有原因** | 任何一次运动，前一拍必须存在引发它的东西（撞击 → 溅开、入场 → 挤压回弹）。凭空出现的动 = 违规 |
| 3 | **承接而非替换** | 相邻两拍切换时，**至少一个元素跨过边界继续动**（`morphBox` / `irisOpen` / `diveInto` / `arcHop`）。整屏换血 = 违规 |
| 4 | **运镜是默认，静止是例外** | 每场 ≥1 次**可测**运镜（`camTrack` / `slowPush` / `whipPan`），并用 `window.__motion(t0,t1)` 报出屏幕位移 px |
| 5 | **硬切只给硬事件** | 纯 `hold` 帧（位移 < 1 格）天然是硬切；**不让运动段被"糊"过去**，也不给静帧加假动 |
| 6 | **快门是运镜的门票** | 屏幕位移 > 80 px/帧的镜头**必须开快门**（`--shutter 180`），否则每帧是一个瞬间、人眼补不出来 → 重影成串 |

> 第 2、3 条是这套范式的**核心**：它们把「一组画面」变成「一条动作链」。
> 只要第 3 条成立，即使每拍只做一个动作，全片也不会读成幻灯片。

## 3. 去模板化：模板只吸纳三层

用户说「不要模板化」时，**不是不用风格库，而是换一种用**。
`references/style-catalog.md` 的 23 个模板，按**吸纳深度**分三层取用：

| 层 | 吸纳什么 | 怎么落地 | 不吸纳什么 |
|---|---|---|---|
| **配色层** | 色板、明度关系、语义色分配 | 写进 `theme.css` 的 CSS 变量 | 模板的版面骨架 |
| **字体层** | 字族搭配、字号级差、字重对比 | 写进 `theme.css` | 模板的排版结构 |
| **时序骨架层** | 入场节奏、停留时长、转场时机 | 转成一串 **t→值** 的时间函数 | 模板的 DOM / 关键帧代码 |

**明确不做的就是「搬画面」**：

- ❌ 复制模板的 `source/index.html` 当骨架，再往里填字 —— 这是「套模板」，成品一眼能看出出处。
- ❌ 把模板的 `@keyframes` 整段搬过来 —— `gsap` 类模板搬进来会得到**静止首帧且零报错**（`lessons.md` #9）。
- ✅ 先用编排器/人工从模板里**只取三层**，再用 `assets/motion.js` 的动作词汇**重新写画面语言**。

> 判据：如果成片能被认出「这是 bold-signal 模板」「这是 swiss-grid 模板」，说明吸纳过头了；
> 如果只能说「颜色像 xx、节奏像 yy」，说明深度对了。

## 4. 帧实现：长度载体 + onUpdate 桥接

渲染器**只认 `window.__tl`（GSAP 时间轴），不调用 `__seek`**。
所以宣传片帧要把「t → 值」的纯时间函数接进时间轴，标准写法：

```js
function render(t) {
  // 全部元素由 HXM.* 时间函数驱动（t 的单位是秒，本场局部时间）
  var c = HXM.camTrack(t, [{t:0,x:0,y:0,zoom:1.06}, {t:DUR,x:24,y:-12,zoom:1.0}]);
  stage.style.transform = HXM.layerMatrix(c, {depth: 0.2});
  // ... 其余元素 ...
}
window.__meta   = { dur: DUR, fps: 30, w: 1920, h: 1080 };
window.__motion = function (t0, t1) { /* 返回这段屏幕最远位移 px，决定快门样本数 */ };

var tl = gsap.timeline({ paused: true, onUpdate: function () { render(this.time()); } });
tl.to({ v: 0 }, { v: 1, duration: DUR, ease: 'none' }, 0);   // 长度载体
window.__tl = tl;
render(0);
if (!window.__MG_RENDER__) {                                  // 人工预览时才自动播
  requestAnimationFrame(function(){ requestAnimationFrame(function(){ tl.play(0); }); });
}
```

**为什么必须这样**：`render_video.mjs` 第 519 行硬性要求帧内存在 `window.__tl`，
它用它来定位每一帧的时刻（seek），**不会去调任何自定义的 `__seek`**。
这个「长度载体 + onUpdate 桥接」是把 motion.js 纯函数接进渲染器的唯一姿势。

## 5. 与其它组件的关系

| 组件 | 在宣传片模式下的用法 |
|---|---|
| `style_director.py` | 仍然跑，但**只采信它的「配色 + 字体 + 节奏骨架」**，忽略「这场套哪个模板」 |
| `render_video.mjs` | 用 `balanced`（含快门）；运动段会因 `__motion` 自动加样本 |
| `check_layout.mjs` | 照跑；纯装饰层（环、光带、安全框）用 DECO token 类名豁免 |

## 6. 自检清单（进渲染前逐条打勾）

- [ ] 每场**只有一个主语**，其余都是它的结果
- [ ] 每场至少存在 1 条**因果链**（A 动 → B 响应），不是并排各动各的
- [ ] 相邻场之间**至少一个元素跨边界继续动**
- [ ] 每场 ≥1 次运镜，且 `__motion` 返回了非零位移
- [ ] 屏幕位移 > 80 px/帧 的镜头已确认走 `--shutter 180`
- [ ] 成片里**认不出**任何单个模板的版面（只认得出配色/节奏的「像」）
